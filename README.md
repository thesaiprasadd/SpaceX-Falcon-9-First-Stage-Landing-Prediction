# 🚀 SpaceX Falcon 9 First-Stage Landing Prediction

An end-to-end **IBM Data Science Capstone Project** that analyzes historical Falcon 9 launch data and uses machine learning to predict first-stage landing success.

### 🔍 Workflow

**Data Collection → Data Wrangling → EDA → SQL → Folium → Dash → Machine Learning**

### 📊 Model Results

| Model | Test Accuracy |
|---|---:|
| Logistic Regression | **83.33%** |
| SVM | **83.33%** |
| Decision Tree | **72.22%** |
| KNN | **83.33%** |

The project also includes interactive geographic analysis with **Folium**, a **Plotly Dash** dashboard, and hyperparameter tuning using **GridSearchCV**.

### 🛠️ Tech Stack

Python • Pandas • NumPy • SQL • Scikit-learn • Matplotlib • Seaborn • Folium • Plotly • Dash • BeautifulSoup


**Key areas:** Data Collection • Data Wrangling • EDA • Machine Learning • Classification • Model Evaluation • Data Visualization • Interactive Dashboards
