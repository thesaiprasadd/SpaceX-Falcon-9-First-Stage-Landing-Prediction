# SpaceX Falcon 9 First Stage Landing Prediction 🚀

A machine learning project that predicts whether the first stage of SpaceX's Falcon 9 rocket will successfully land and be reused. The project uses publicly available launch data, data preprocessing, exploratory analysis, machine learning classification models, and interactive dashboards to identify the factors influencing successful first-stage recovery.

The goal is to help a competing rocket company estimate launch costs, as successful first-stage reuse can significantly reduce the cost of future launches.

**Key areas:** Data Collection • Data Wrangling • EDA • Machine Learning • Classification • Model Evaluation • Data Visualization • Interactive Dashboards
